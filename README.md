# **API-ETL-Project**  
### **Vancouver API Data ETL & Visualization**  

This project automates the extraction, transformation, and loading (ETL) of **public datasets** from the City of Vancouver. The processed data is analyzed and visualized using **Power BI** to provide actionable insights for decision-makers across various **Vancouver city programs and councils**.

---

### **Project Overview**  
The project addresses critical urban and community needs by leveraging open data APIs, ETL pipelines, and interactive dashboards. Key areas of focus include:  

1. **Homeless Shelters and Social Services**  
2. **Non-Market Housing and Urban Planning**  
3. **Vancouver Food Policy Initiatives**  
4. **Real Estate and Rental Compliance**  
5. **Community Garden and Food Tree Programs**  

By centralizing and visualizing these datasets, the project supports **data-driven decision-making** for public agencies, councils, and policymakers in Vancouver.

---

### **Key Features**  
- **Automated ETL Pipeline**:  
   - Python scripts handle **data extraction** from APIs, **transformation** for consistency, and storage into a PostgreSQL database.  
   - Reduces manual data handling, ensuring accuracy and efficiency.  

- **Dynamic Data Storage**:  
   - Relevant data is stored in **PostgreSQL**, enabling easy querying, analysis, and scalability for future datasets.  

- **Interactive Power BI Dashboards**:  
   - Custom-built dashboards provide **real-time insights** on critical city programs.  
   - Visualizations include **maps, trends, KPIs**, and **filtered analytics** for informed decision-making.

---

### **Value for Vancouver City Programs**  
This project is designed to empower councils and city departments:  

- **Vancouver Food Policy Council**:  
   - Understand food accessibility with data on community gardens and food trees.  

- **Urban Planning & Housing**:  
   - Analyze **non-market housing** availability and trends to improve housing strategies.  

- **Social Programs**:  
   - Visualize data on **homeless shelters** to identify gaps in support systems.  

- **Real Estate Compliance**:  
   - Track urban growth and monitor rental compliance programs effectively.  

By connecting various public programs through data analytics, this project enhances **collaboration and transparency** across Vancouver’s civic ecosystem.

### **How to Use**  

1. **Download the Project Files**:  
   - Clone this repository or download the files directly.  
   - Ensure you have [Power BI Desktop](https://powerbi.microsoft.com/en-us/downloads/) installed to interact with dashboards.  

2. **Access Dashboards**:  
   - Navigate to the `Power BI` folder.  
   - Open the `Dashboards.pbix` file using Power BI Desktop.  

3. **Explore Key Visualizations**:  
   - Use filters, slicers, and map interactivity to analyze specific programs and trends.  

---

### **Project Architecture**  
1. **Data Extraction**:  
   - Data fetched from Vancouver’s open APIs using Python scripts.  

2. **Transformation & Storage**:  
   - Cleaned and standardized data stored in PostgreSQL.  

3. **Visualization**:  
   - Interactive dashboards created in Power BI for analysis and reporting.  

---

### **Technologies Used**  
- **Python**: Data extraction and cleaning (requests, pandas).  
- **PostgreSQL**: Data storage and querying.  
- **Power BI**: Visualization and interactive dashboards.  
- **APIs**: Open data APIs provided by the City of Vancouver.
